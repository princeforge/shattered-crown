# Screenshot Capture Guide — Hero Defence: Shattered Crown

Google Play requires **minimum 2 screenshots**, but **4-8 is recommended** for best conversion.
Screenshots should be **1920×1080** (landscape) or **1080×1920** (portrait). Since your game
is landscape-locked, use **1920×1080**.

## How to Capture Screenshots

### From Godot editor (desktop)
1. Run the game in the editor (F5)
2. Press **F12** to take a screenshot (saves to project root as `screenshot_NNN.png`)
   - If F12 doesn't work, use your OS screenshot tool:
     - Windows: **Win + Shift + S** (Snipping Tool)
     - Or press **PrtScn** and paste into an image editor

### From Android device
1. Build and install the APK on your device
2. Navigate to the screen you want to capture
3. Press **Power + Volume Down** simultaneously
4. Screenshots save to your Photos/Gallery

### Recommended: Capture at 1920×1080
The game's viewport is 1920×1080, so screenshots from the desktop editor will be
exactly the right resolution. If capturing from a device, crop/resize to 1920×1080.

## Adding Captions to Screenshots

You can add captions using any image editor:
- **GIMP** (free): Open screenshot, add text layer, export
- **Paint.NET** (free, Windows): Open, add text, save
- **Canva** (free online): Upload, add text overlay, download
- **Figma** (free online): Create a frame, add screenshot + text

### Caption style recommendations:
- **Font**: Bold sans-serif (Arial, Roboto, or Montserrat)
- **Size**: 36-48px (readable on mobile)
- **Color**: White with dark drop shadow, or gold (#FFD700) on dark background
- **Position**: Bottom-left or bottom-center (doesn't obscure gameplay)
- **Background**: Semi-transparent dark bar behind text for readability

## Upload to Play Console

1. Go to Play Console → Your app → Grow → Store presence → Main store listing
2. Scroll to "Screenshots" section
3. Upload 4-8 screenshots (1920×1080 PNG or JPEG)
4. Drag to reorder (put the best action shot first)
5. Save

## Notes
- Screenshots must not contain device frames, borders, or watermarks
- Screenshots must match the actual gameplay (no mockups or concept art)
- Avoid showing debug overlays or editor UI
- If your game has different biomes, try to show variety across screenshots
